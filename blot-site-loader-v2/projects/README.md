# /projects

Drop your project files here, named 001 through 072 to match what
buildProjects() in index.html generates (e.g. 001.png, 013.mp4 — every
13th project is set up as video, the rest as image; see mediaType in
that function if you want to change which ones are video).

Until a given file exists, that tile just shows its generated
placeholder mark — nothing looks broken.
